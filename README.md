- 사진 다중 업로드, 컷별 순서/삭제/표시 시간(1.5~6초, 0.1초 단위)/모션(줌인·줌아웃·패닝·고정)/자막

- 자막: 숏폼 스타일 무박스 흰 글씨, 첫 컷은 큰 후킹 타이틀, 크기·위치(하단/중앙) 조절

- 영상 저장: `MediaRecorder` — 아이폰 Safari는 MP4, 크롬은 WebM (실패 시 자동으로 다른 형식 재시도), 진행률 표시
